# نقشه مخزن اسناد — پلتفرم هوش سازمانی

این مخزن، مستندات و مصنوعات فنی «پلتفرم هوش سازمانی» را نگه می‌دارد: دو محصول (A: مغز دوم سازمانی، B: گزارش‌گیری و تحلیل عملکرد واحدها) روی یک هسته مشترک. مبنا: `executive-plan-organizational-intelligence-platform.md` نسخه ۱.۰.

## قاعده «هر تصمیم = یک ADR»

هر تصمیم معماری قابل توجه (انتخاب مدل، الگوی اتصال، ساختار داده، تغییر شکسته در قرارداد یکپارچگی) باید در یک فایل مستقل در `decisions/` با نام `ADR-XXXX-عنوان-کوتاه.md` ثبت شود، بر اساس `decisions/ADR-TEMPLATE.md`. شامل: تاریخ، وضعیت، گزینه‌های بررسی‌شده، تصمیم و دلیل.

## برچسب‌گذاری محتوا

هر سند یا بخشی که پیشنهاد این مخزن است (نه تصمیم مصوب سازمانی) باید با «**[پیشنهادی — نیازمند تأیید]**» علامت بخورد. هرجا داده یا عددی معلوم نیست، `TBD` با توضیح کوتاه علت.
