# BPMS_INTEGRATION.md — الگوهای اتصال به BPMS

> **هدف این فایل:** چهار الگوی اتصال (View فقط‌خواندنی، API رسمی، Webhook، خروجی زمان‌بندی‌شده)، توصیه ترکیبی، لایه Staging اجباری (Landing → Validated → Warehouse)، و فرض‌های صریح ثبت‌شده در `ASSUMPTIONS.md` چون ساختار واقعی BPMS هنوز نامعلوم است.

## وضعیت
اسکلت WP-1 — محتوای تفصیلی خارج از دامنه WP-1 تا WP-8 فعلی (طبق بریف، اتصال واقعی BPMS خارج از دامنه این اسپرینت است)؛ در صورت نیاز به‌عنوان بسته کاری جدا تعریف می‌شود.
