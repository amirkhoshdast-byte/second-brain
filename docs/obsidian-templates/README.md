# الگوهای Obsidian — پلتفرم هوش سازمانی

> **هدف این پوشه:** Frontmatter کامل + ساختار بخش‌ها برای هر نوع موجودیت دانشی. این فایل‌ها باید در `90_Templates/` Vault Obsidian کپی شوند.

**[پیشنهادی — نیازمند تأیید]**

## فایل‌ها

| فایل | موجودیت | محصول |
|---|---|---|
| `country.md` | Country — کشور | A |
| `organization.md` | Organization — سازمان بیرونی | A |
| `person.md` | Person — شخص | A |
| `report.md` | Report — گزارش | A + B |
| `signal.md` | Signal — سیگنال | A |
| `insight.md` | Insight — بینش تحلیلی | A |
| `issue.md` | Issue — مسئله | A + B |
| `decision.md` | Decision — تصمیم | A + B |
| `unit.md` | Unit — واحد سازمانی داخلی | B |
| `indicator.md` | Indicator — شاخص عملکردی | A + B |

## قواعد کلی

- هر فیلد `TBD` به معنای «در زمان ایجاد Note باید پر شود» است.
- فیلدهایی که `[]` هستند لیست‌اند — هر مقدار با `[[wikilink]]` مرتبط می‌شود.
- `classification` را همیشه اول پر کن — تعیین می‌کند چه کسی می‌تواند این Note را ببیند.
- هر Note باید حداقل یک `[[wikilink]]` داشته باشد — موجودیت ایزوله بی‌معنی است.
